1. المعمارية الهيكلية والبنية التقنية للنظام

نظام المدارس السحابي الآمن (Secure Cloud School System) هو منصة سحابية شاملة ومصممة بتقنية تعدد المستأجرين (Multi-Tenant) لتشغيل المنظومة التعليمية والإدارية والمالية لعدة مدارس بشكل مستقّل وآمن.

  • الخلفية البرمجية (Backend): تعتمد على إطار FastAPI (Python) للتعامل مع API غير متزامن فائق السرعة، مع SQLAlchemy Async ORM ومحرك ترحيل قواعد البيانات Alembic.
  • قاعدة البيانات (Database): PostgreSQL مع فصل كامل لبيانات المدارس برابط المعرف school_id.
  • الأمان والتوثيق (Security & Auth): تشفير كلمات المرور بحسب معيار Bcrypt وتأمين الجلسات باستخدام JWT Tokens.
  • التوثيق بالبلوكشين (Blockchain Verification): محرك تشفير مستقّل يولد بصمة رقمية (Hash) موثقة لشهادات الطلاب ودرجاتهم لمنع التزوير.
  • الواجهة الأمامية (Frontend): تطبيق صفحة واحدة (SPA) باستعمال Vanilla JS & CSS المتقدم لدعم Glassmorphism و Responsive Design.

إعدادات النظام (pg-system-settings) اللغة، السنة المالكة الافتراضية، خيارات الطباعة، التنبيهات. تحديث الإعدادات العامة والتفضيلات البرمجية.

التنبيهات التلقائية (pg-alerts) نصوص التنبيهات، الفئة المستهدفة، التاريخ والوقت. إرسال تنبيه جماعي، جدولة الإشعارات.
الأرشيف (pg-archive) الملفات المؤرشفة، سنة الأرشيف، نوع السجل. استرجاع البيانات المؤرشفة، أرشفة سنة أكاديمية سابقة.
تغيير كلمة المرور (pg-change-password) كلمة المرور الحالية، كلمة المرور الجديدة، تأكيد كلمة المرور. حفظ وتحديث كلمة المرور.
إدارة الترحيلات (pg-posting) القيود والسندات غير المرحّلة، الفترة المالية. ترحيل العمليات الماليّة نهائياً للدفاتر، إلغاء الترحيل.
إدارة قواعد البيانات (pg-db-management) حالة الاتصال، النسخ الاحتياطية، حجم البيانات. إنشاء نسخة احتياطية (Backup)، استعادة البيانات (Restore).

قائمة المركز المالي (pg-balance-sheet) إجمالي الأصول المتداولة والابتكارية، الخصوم وحقوق الملكية. عرض الميزانية العمومية الشاملة.

التقويم المدرسي (pg-academic-calendar) التاريخ، المناسبة (بدء الدراسة/امتحانات/إجازة). إضافة وتعديل أحداث التقويم المدرسي.

أنواع الدرجات (pg-grade-types) نوع الاختيار (واجبات/شفهي/مواظبة/شهري/نهائي). تحديد أوزان ونسب تقييم الدرجات.

فئات الخصم (pg-discount-categories) اسم الخصم (تفوق/أخوة/أبناء عاملين)، النسبة/المبلغ. تحديد قواعد وسياسات الخصومات.

إعارة الكتب (pg-book-borrows) اسم المستعير، الكتاب، تاريخ الإعارة والترجيع. تسجيل إعارة واستلام الكتاب.
المقصف المدرسي (pg-canteen) المنتجات، الأسعار، المبيعات اليومية. إدارة الأصناف ورصد مبيعات المقصف.
السجل الصحي (pg-health-records) الأمراض المزمنة، الحساسية، الإسعافات المقدمة. تسجيل الحالة الصحية للطلاب.
الأنشطة والرحلات (pg-activities) اسم النشاط، موعد الرحلة، رسوم المشاركة. تنظيم الأنشطة المدرسية والرحلات.

اللوحة الرئيسية للمدرسة (pg-dashboard) إحصائيات الطلاب، الحضور، الإيرادات، الرسم البياني. متابعة مؤشرات الأداء اللحظية للمدرسة.
لوحة تحكم السحاب (pg-saas-admin) قائمة المدارس، الاشتراكات، الإحصائيات الشاملة. إدارة المنصة السحابية والعملاء.

مالية ولي الأمر (pg-parent-fees) رسوم كل ابن، المدفوع، المتبقي، إيصالات القبض. استعراض وتأكيد السداد المالي للأبناء.
حضور الأبناء (pg-parent-attendance) جدول غياب وحضور الأبناء والأسباب. متابعة انضباط الأبناء في المدرسة.
درجات الأبناء (pg-parent-grades) نتائج وتفاصيل الاختبارات مع **رمز البصمة الرقمية**. معاينة وطباعة شهادات ودرجات الأبناء.
4. معمارية الربط وتدفق البيانات بين الواجهات وقاعدة البيانات

دورة التكامل والتدفق المستمر للبيانات:

  1. الدخول والتحقق (Authentication): عند دخول المستخدم عبر loginForm، يستقبل النظام الـ Token و school_id ويحفظها في الجلسة، ثم توجه الدالة goTo(...) المستخدم للواجهة المستهدفة.
  2. التكامل بين التسجيل والمالية: إضافة طالب جديد ينشئ فوراً سلفاً وحساباً ذمية لولي الأمر في FinancialRecord مع إمكانية جدولة الأقساط تلقائياً.
  3. التكامل بين رصد الدرجات والبلوكشين: عند رصد المعلم للدرجة في pg-grade-entry، يتم حساب هاش SHA-256 موثق يربط بين (الطالب + المادة + الدرجة + المدرسة)، وتخزن الشفرة لتمكين ولي الأمر والجهات الخارجية من مطابقتها في pg-blockchain-verify.
  4. الربط المحاسبي التلقائي: تحصيل أي قسط عبر pg-voucher-receipt يولد قيد يومية متوازن يرحل تلقائياً لدفتر الاستاد، وينعكس فلياً في كشف الحساب، ميزان المراجعة، وقائمة الدخل.
